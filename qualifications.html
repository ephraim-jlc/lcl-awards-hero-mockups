Other implications

  1. The page title is no longer repeated. The coloured heading at the top of the body copy goes, because the Hero Title replaces it. The blue "Qualifications" heading above the intro goes.
  2. Hero images need a clear area on the left. The text now sits on the left of the image, and the existing images were cropped for text at the bottom right. The wind turbine image works with text on the left if it is darkened, but the blue overlay and chevron need to stay clear of the text.
  3. Section colour is kept. The hero tint, the chevron and the bar under the hero use the section colour, as on the current site. Link text uses a darker version of that colour so it passes contrast on white. Primary CTA colours follow the same rule.
  4. The body needs a width limit. Without the left column, body copy would run the full page width. The mockup limits running text to about 760px.
  5. The hero can be shorter. The current hero is about half the height of a laptop screen. The mockup uses about 420px, which brings the first paragraph into view.
  6. Breadcrumbs stay directly under the hero.
